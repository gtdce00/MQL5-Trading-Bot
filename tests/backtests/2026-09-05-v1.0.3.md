## Expected-negative input safety test

- Test profile requested 0.5% risk across two allowed positions while the
  maximum daily loss was only 0.5%.
- `OnInit` rejected the profile with
  `aggregate position risk exceeds daily loss limit`.
- Tester recorded incorrect input parameters and zero trades, as expected.
- This is a passing safety test, not a failed strategy run.

## Assessment

Risk state now survives a normal EA/terminal restart outside the tester, while
tester runs remain isolated and reproducible. The strategy itself is still
unprofitable and must not be used for live trading. Trend/regime research,
out-of-sample testing, and walk-forward validation remain required.
