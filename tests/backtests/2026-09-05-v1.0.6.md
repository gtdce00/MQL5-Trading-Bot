## Safety changes under test

- Terminal risk state includes server/account/magic scope and integrity marker.
- Peak equity and active locks are persisted monotonically.
- Missing current-day state locks live/demo execution until the next day.
- Live execution permits one fail-closed instance per
  terminal/server/account/magic; risk state is rechecked immediately before
  submission and by a one-second account-risk timer.
- A close is complete only after a full completion retcode and position removal.
- Live/demo execution rejects netting and exchange-execution accounts.
- Position sizing uses broker stop profit, configured slippage and a 10% cost
  reserve; this is conservative gross stop-risk sizing, not a guaranteed
  all-cost loss bound.

The static suite checks source invariants. Strategy Tester bypasses terminal
state persistence, and the live-disabled demo smoke does not exercise order
submission. Behavioral live concurrency and rollover tests remain required.

## Assessment

v1.0.6 hardens trade safety but does not make the strategy profitable.
The EA remains experimental, live trading remains disabled by default, and
no profitability/readiness claim is made. The next strategy change must
predefine a trend/regime hypothesis and acceptance criteria, then use
separate in-sample, out-of-sample and walk-forward tests.
